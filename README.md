# Task 3: Data Visualization and Dashboard

## Project Objective
To transform raw data into meaningful visualizations and a dashboard that helps identify product sales patterns, profit performance, and relationships between numerical variables.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code

## Dataset
The dataset contains product names, categories, sales amounts, and profit values.

## Visualizations Created
1. **Product Sales Bar Chart:** Compares sales across products.
2. **Profit Analysis Bar Chart:** Compares profit earned by each product.
3. **Correlation Heatmap:** Examines the relationship between sales and profit.
4. **Sales and Profit Dashboard:** Combines multiple visualizations and summary metrics in one view.

## Key Findings
- Laptop has the highest sales value of 50,000.
- Headphones has the lowest sales value of 5,000.
- Total sales are 122,000.
- Total profit is 21,500.
- The dataset contains six unique products.
- Sales and profit show a positive relationship in this sample dataset.

## Project Files
- `data.csv` — Sample dataset.
- `visualization.py` — Product sales visualization.
- `profit_analysis.py` — Profit chart and correlation heatmap.
- `dashboard.py` — Combined dashboard.
- `dashboard.png` — Saved dashboard image.

## Conclusion
This project demonstrates how Python visualization libraries can transform raw data into understandable charts and dashboards. The visualizations make it easier to compare product performance and identify patterns that may support business decisions.
